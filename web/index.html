The summary above is generated with no AI at all — it's plain JavaScript templating over the numbers, so it's always available. For a more nuanced, conversational explanation of your specific situation, this optionally calls the same explainProjection() function from the open-source library, which narrates the numbers above without inventing new ones. Paste your own Anthropic API key to try it (never sent anywhere but directly to Anthropic's API from your browser).


TaxBombAI is an educational projection tool, not tax or financial advice. RMD divisors sourced from IRS Publication 590-B, Table III. Verify current-year tax brackets before relying on this for real decisions. Full methodology and source code: github.com/jitendrarout/taxbombai
